# PolyKybd v1.13.9 Agent pages
The protocol moves to 36. PolyKybdHost 1.27.6 uses it for the page number on Esc and the AI-key ripple. Older hosts from 1.22.16 on still work with this firmware.

## 1.13.9: Agent pages 🤖
- **Esc shows "Next" with the page, e.g. "1/2",** while there is more than one page of agents.
- **The AI key ripples when an agent on another page waits or finishes.** Switching pages no longer makes a key ring as if its agent had just finished.
- **Leaving AI mode tells the host to go back to page 1.**

## 1.13.8: Overlays after a suspend
Overlays now come back on when the keyboard wakes from a suspend.
