# PolyKybd v1.5.0 Demo mode

**Protocol stays at 21.** No host update is needed. Host 1.7.0 and this firmware can be updated independently.

## 1.5.0: Demo mode 🎬
A 15-minute showroom loop for a booth or a shop window.

- **Start it from the settings layer, behind `More…`.** On split72 it is on the row that appears; on split42 it sits on the top row, beside the glyph-script key. It types, opens the language and emoji menus, tours 13 languages and 9 glyph scripts, and rests in your idle animation between rounds.
- **Hold Esc for 2 s to stop.** Taps and other keys do nothing, and no key reaches the computer while it runs. The status panels show how to exit every 12 s.
- **No computer needed:** it also runs on a USB charger or a power bank.

## 1.4.2: Crash fix for missing legend characters 🛠️
- **A keycap legend using a character no font had could crash the keyboard.** Armenian's Shift layer did it (em dash), and switching to that layout rebooted the keyboard. Such a character now draws as `!` instead of crashing.
- **The four missing characters are now included:** em dash, ellipsis and one-dot leader (Armenian), and the right quote (Romanian AltGr).

## 1.4.0 – 1.4.1: Animated status panels on split72 ✨
- **The idle status panels show plasma bands with "Poly Kybd" typed across both halves,** replacing the old scrolling logos.
- **The Eden idle animation on the keycaps now runs on the second CPU core,** so the status panels animate alongside it instead of taking turns.

## 1.3.3: Overlay icons on swapped-letter layouts
With the host's recent-apps mode, layouts that swap letters (de-DE Y/Z, fr-FR A/Q and Z/W) could show an icon on the wrong keycap. Icons now land where the app put them.
