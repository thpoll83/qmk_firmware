# PolyKybd v1.7.3 Key demo
**Protocol stays at 22.** No host update is needed. PolyKybdHost 1.15.0 and this firmware can be updated independently.

## 1.7.3: Key demo ⌨️
- **New `Key Demo` key on the settings layer, behind `More…`, next to `Demo Mode`.** It plays the same loop and also types its text into the computer, line by line, so a text editor fills up as a long typing test.
- **It never sends a modifier.** No Shift, Ctrl, Alt, GUI or Tab reaches the computer, so a run cannot switch windows or trigger a shortcut. Capitals and symbols arrive as their unshifted key.
- ⚠️ **Click into the editor first.** It types into whatever window has focus. Hold Esc for 2 s to stop.
- **Both demos now type the idle-screen poems** instead of their own sentences, which saves about 900 bytes of flash.

## 1.7.2: Poems on the idle status panels ✨
- **On split72, the idle status panels now type a short poem after "Poly Kybd"**, then delete it again with Backspace. There are five poems, picked at random each round and never the same twice in a row. Both halves type the same poem.
