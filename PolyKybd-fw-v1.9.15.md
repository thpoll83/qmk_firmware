# PolyKybd v1.9.15 Symbols in the emoji picker

**Protocol moves to 25.** Update PolyKybdHost to 1.17.82 first. Older apps still connect, but overlay keys keep their legend, and the new math symbols and arrows show *Glyph missing!* because only the new app ships the font pack that has them.

## 1.9.15: Symbols in the emoji picker 🔣
- **The Symbols tab (✔) now has about 200 typographic and technical symbols:** superscripts, subscripts, every fraction, currency signs, Greek letters, math operators and arrows. ¹ is the second key on the tab.
- **Page keys show where you are**, for example ▶ 3/9, in the emoji, language and Intl accent pickers.
- **A key whose glyph is missing shows *Glyph missing!*** instead of "!". This happens when the font pack that has the glyph is not on the keyboard.
- ⚠️ A recently used symbol from the Symbols tab can show a different symbol once, because the tab's order changed.

## 1.9.13: Overlay keys without the key legend 🎨
An overlay can now replace a key completely, for example a game's ESC mark. Needs PolyKybdHost 1.17.82.
